# 翠路ロジスティクス｜積む。守る。届け切れ！

架空の運送会社「翠路ロジスティクス株式会社」のコーポレートサイトと、その社内安全アカデミーという設定の2Dブラウザゲームです。パレット荷役、重量、重心、破損防止、荷崩れ防止、運賃と利益を2画面で学べます。外部ライブラリやビルド作業は不要です。

起動時は緑と青を基調にした架空企業ホームページが表示されます。3枚の生成画像が切り替わるメインビジュアル、流れる安全メッセージ、事業紹介、企業理念、架空の代表・各エリア責任者のメッセージ、採用情報、研修品質、制限時間、4ステップの遊び方を確認できます。ホームの「ウェブ版」「スマホ版」は、それぞれの操作UIを新しいタブで開きます。

会社名、人物、事業所、役職、コメントはすべて架空です。サイトにも実在する企業・団体・人物と関係がない旨を明記し、住所・電話番号・応募フォームは設けていません。人物写真はAI生成した架空人物です。

## 起動

このフォルダーで、共有売上API付きの開発サーバーを起動します。

```powershell
node server.js
```

その後、ブラウザで `http://localhost:8000` を開きます。

`python -m http.server 8000` や `index.html` の直接表示でもゲーム自体は遊べますが、右上の「みんなの累計安全売上」は「集計サーバー未接続」と表示されます。

## みんなの累計安全売上

- クリアした便の安全売上を `POST /api/community-revenue` でサーバーへ加算します。
- 合計売上と安全配送便数は `data/community-revenue.json` に保存され、同じサーバーへアクセスする全プレイヤーで共有されます。
- 同じ配送結果の再送は完了IDで重複排除します。
- プレイヤー名、メールアドレスなどの個人情報は送信・保存しません。
- ローカル起動ではそのPCの共有合計です。インターネット上の全プレイヤーで共有するには、このサーバーを1つの公開環境へ配置し、永続ディスクを割り当ててください。本格運用では認証、レート制限、データベース化も必要です。

## 遊び方

### 表示・配送操作の更新

段積み荷役は上段穴の高さから18px以内なら、爪突きではなく差し込み可能と判定します。高さ・前進・差込量を自動変更しません。手動で75%以上差し込んでから上ボタン／Wで持上げ。搬送中も上・下で爪と荷物を昇降できます。

PCの操作：荷役はW/S＝爪の上下、A/D＝リフト左右移動、E＝持上げ。配送はW/↑＝加速、S/↓/スペース＝減速、A/D/←→＝車線変更、P/Esc＝一時停止。
配送中の右上「一時停止」で時間・交通・判定を停止し、「再開」で続行します。再開時には加速・減速入力を解除して押しっぱなしを防ぎます。

ゲームの内部解像度は1280×720固定。表示は16:9を維持して画面の高さ・操作欄に合わせて縮小します。極端に小さい画面ではスクロールで操作欄を確認できます。
スマホの配送は仮想十字パッド（上＝加速、左右＝車線変更、下＝減速）で操作します。

### 新しい荷役・夜間配送

スマホの積載ナビはCanvasの外、仮想パッドの上へ移動しました。荷物には重なりません。
第1便は基本荷役、第2便から段積み、第3便から前後配置が登場します。
段積みは上段をタップして選択し、先に取り出します。下段を持ち上げると上下の荷物が転倒し、両方が破損扱いになります。
下段が選択中でも、上段のパレット穴へ爪を合わせれば上段を自動で判定対象にします。見えているパレットの穴と同じ座標で高さ・75%以上の差込を判定し、荷物に触れていない高さでは爪突き破損にしません。
前後配置は手前から取り出します。差込75%以上で停止し、爪先を奥の貨物まで進めると奥の貨物が破損します。

点検後の出発で、夜間高速配送（アーケード風）に移ります。
- 3車線の高速道路。トラックは最高90km/h（速度リミッター）で、スタートは60km/h。アクセルを離すとその速度で巡航します。積荷が重いほど加速が鈍くなります。
- 周りの車は常に流れています。左車線は遅いトラックや乗用車、中央は普通の流れ、右車線は速い車が後ろから追い越していきます。車は前の車との車間を取り、ウインカーを出して車線変更します。
- コースは毎回変わります。工事の車線規制（制限60）、落下物、故障車（ハザード点灯）、渋滞（ハザードの車列）、左からの合流、トンネル（制限70）が順不同で現れ、最後に出口があります。出口では左車線にいないと通過扱いになり、25秒の遠回りになります。
- パトカーは一部の便にだけ現れます。制限速度を超えたまま追い越すと速度超過です。
- 制限速度の区間で1.5秒以上超過すると速度超過（−3点）。区間を無事故・制限内で抜けると区間クリアのボーナスです。
- 車や障害物への接触は−5点（対象ごとに1回）。後ろから来た車に追突されることはなく、割り込み車は引き返します。
- 高速での車線変更やブレーキで「荷揺れ」がたまり、満タンになると荷傷み（−5点）。支えの足りない荷物・高重心・偏荷重・未固定の荷物があると揺れやすくなります。
- 遅い車を別の車線から追い越すとコンボが伸び、運転ポイントが増えます。接触や荷傷みでコンボは途切れます。
- 到着目安（コースごとに計算）を過ぎると、5秒ごとに500円の減収です。接触・速度超過・荷傷みは安全点だけを下げ、運賃は減りません。
速度・費用・道路構成はゲーム用の値で、実際の道路の制限速度や処分を表すものではありません。

1. 画面1「パレット荷役」で、荷札の重量・運賃・注意表示を確認します。
2. 青い昇降ハンドルを上下へドラッグし、爪先の高さをパレット差込口の中央へ合わせます。
3. フォークリフト車体を右へドラッグして静かに前進します。高さを外したまま荷へ押し込むと爪突き事故となり、貨物は破損隔離・運賃対象外です。
4. 爪をパレット奥行きの75%以上まで差し込むと持上げできます。荷を低く保ち、車体を左へドラッグして出荷バースへ後退搬送します。
5. 「積付け画面へ」で画面2へ移り、搬送済みパレットを側面図のトラック荷室へ直接ドラッグして積みます。
6. 重い物は低く、前後荷重は中央へ。荷物を選び、コンパネ・発泡材・ラッシングベルトで固定します。
7. 「発車前点検」で過積載、偏荷重、耐荷重、破損厳禁、固定、爪突き事故を確認します。
8. 点検に合格したら出発し、安全売上と安全スコアを確認します。

荷物を積み直すときは、荷台から下の待機場へドラッグして戻せます。`R` は回転、`Z` はひとつ戻す、`1`〜`3` は資材、`I` は点検です。

スマホ版では、画面下のバーチャルパッドを押している間だけ操作が続きます。左パッドで後退・前進、右パッドで爪を上げ下げし、中央の「持上げ」で差込判定を確定します。荷を持ち上げて左端の緑トラックへ後退すると搬送完了です。指を離す、ブラウザが非表示になる、または別アプリへ切り替わると入力は停止します。

各ミッションの制限時間は2分30秒〜5分です。0秒になっても作業は続行できますが、超過後は5秒ごとに500円の遅延損失が安全売上から差し引かれます。残り30秒になるとゲーム内タイマーが警告色へ変わります。

## 役職と配車便

研修生から始まり、MISSION 01〜05をクリアするごとに荷役スタッフ→乗務員→積付けリーダー→班長→配車係へ昇進します。昇進すると結果画面に辞令が表示されます（氏名・コメントは架空です）。

出発前には統括部長・所長・社長が便の目的を伝え、先輩と同期が励まします（立ち絵と表情つきの会話）。帰社すると結果に応じた評価と同僚からのひと言があります。初めてクリアした便では、荷役・積付け・運転・収益の人事評価シートが順に出たあと「昇格」の判が押され、紙吹雪の中で社長と同僚が祝福します。会話はスキップでき、ミッション選択の「会話 ON/OFF」で表示を切り替えられます（登場人物はすべて架空です）。

配車係になると「配車便」に挑戦できます。12件の依頼から受ける荷物を選び、いつもどおり荷役・積付け・配送を行います。依頼ボードには重量、固定資材、破損厳禁と発泡材、見込み安全売上が表示されます。受けたのに積まなかった荷物は運賃の50%が違約金になるため、「積めるかどうか」を考えて受注します。配車便を1回クリアすると営業所長になります。配車便の記録は5便のキャンペーン目標や共有売上には含めません。

## 研修内容

- 荷物ごとの実重量（kg）と車両の最大積載量
- 重い荷物を床へ置くこと、前後荷重と重心の管理
- ガラス、精密機器、ペットケージなど破損厳禁貨物の上積み禁止・天地無用
- コンパネによる押さえ、発泡材による隙間充填、ラッシングベルトによる固定
- 荷降ろし順を考えた配置
- 発車前点検と、積み直し後の再点検
- フォークリフトの爪を荷物の幅の75%以上まで差し込む積み取り判定
- パレット差込口と爪先の高さ判定、誤進入による爪突き事故・破損隔離
- 倉庫内の低い荷姿での後退搬送と、トラック後部からの積付けを分けた2工程
- 運賃、資材費、破損損失、遅延損失を差し引いた「安全売上」
- 各便の最高安全売上を合算する本日の目標金額
