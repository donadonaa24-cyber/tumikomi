# 積載研修：積めるもんなら積んでみろ！

パレット荷役、重量、重心、破損防止、荷崩れ防止、運賃と利益を2画面で学ぶ2Dブラウザゲームです。外部ライブラリやビルド作業は不要です。

起動時はゲーム専用ホームページが表示されます。ゲーム概要、学べる内容、4ステップの遊び方を確認し、「無料で研修を始める」または「ミッション選択」から研修へ進めます。

## 起動

`index.html` をブラウザで直接開くか、このフォルダーで簡易HTTPサーバーを起動します。

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 遊び方

1. 画面1「パレット荷役」で、荷札の重量・運賃・注意表示を確認します。
2. 黄色い昇降ハンドルを上下へドラッグし、爪先の高さをパレット差込口の中央へ合わせます。
3. フォークリフト車体を右へドラッグして静かに前進します。高さを外したまま荷へ押し込むと爪突き事故となり、貨物は破損隔離・運賃対象外です。
4. 爪をパレット奥行きの75%以上まで差し込むと持上げできます。荷を低く保ち、車体を左へドラッグして出荷バースへ後退搬送します。
5. 「積付け画面へ」で画面2へ移り、搬送済みパレットを側面図のトラック荷室へ直接ドラッグして積みます。
6. 重い物は低く、前後荷重は中央へ。荷物を選び、コンパネ・発泡材・ラッシングベルトで固定します。
7. 「発車前点検」で過積載、偏荷重、耐荷重、破損厳禁、固定、爪突き事故を確認します。
8. 点検に合格したら出発し、安全売上と安全スコアを確認します。

荷物を積み直すときは、荷台から下の待機場へドラッグして戻せます。`R` は回転、`Z` はひとつ戻す、`1`〜`3` は資材、`I` は点検です。

## 研修内容

- 荷物ごとの実重量（kg）と車両の最大積載量
- 重い荷物を床へ置くこと、前後荷重と重心の管理
- ガラス、精密機器、ペットケージなど破損厳禁貨物の上積み禁止・天地無用
- コンパネによる押さえ、発泡材による隙間充填、ラッシングベルトによる固定
- 荷降ろし順を考えた配置
- 発車前点検と、積み直し後の再点検
- フォークリフトの爪を荷物の幅の75%以上まで差し込む積み取り判定
- パレット差込口と爪先の高さ判定、誤進入による爪突き事故・破損隔離
- 倉庫内の低い荷姿での後退搬送と、トラック後部からの積付けを分けた2工程
- 運賃、資材費、破損損失、遅延損失を差し引いた「安全売上」
- 各便の最高安全売上を合算する本日の目標金額

## 学習ルールの参考

ゲーム内の判定は、次の公的資料にある基本原則を遊びやすく単純化しています。

- 国土交通省「自動車運送事業者が運転者に対して行う指導及び監督の指針」関連資料（偏荷重、荷崩れ、貨物の固縛）
  - https://wwwtb.mlit.go.jp/hokushin/content/000322705.pdf
- 国土交通省「偏荷重や荷崩れを防ぐ正しい固縛方法」
  - https://www.mlit.go.jp/jidosha/anzen/03safety/resourse/data/truck_honpen_miekeshi.pdf
- 厚生労働省「陸上貨物運送事業における荷役作業の安全対策ガイドライン」
  - https://www.mhlw.go.jp/web/t_doc?dataId=00tb9284&dataType=1&pageNo=1
- 厚生労働省「フォークリフト運転技能講習テキスト」（爪を水平にし、根元まで深く差し込む積み取り手順）
  - https://www.mhlw.go.jp/content/11300000/000628483.pdf
- 厚生労働省「見極めチェックリスト：フォークリフト基本動作」（爪先確認、静かな抜き差し、根元までの差込み、爪先破損防止）
  - https://www.mhlw.go.jp/file/06-Seisakujouhou-11300000-Roudoukijunkyokuanzeneiseibu/rikuunmanual_2.pdf
- 厚生労働省「フォークリフトの爪をパレットに差し込む時」のヒヤリ・ハット事例（周囲立入・声掛け・警報）
  - https://anzeninfo.mhlw.go.jp/hiyari/hiy_0406.html
- 英国政府 DVSA「Securing loads on HGVs and goods vehicles」（低重心、重量配分、隙間充填、固縛）
  - https://www.gov.uk/guidance/securing-loads-on-hgvs-and-goods-vehicles/2-load-securing-the-basics
  - https://www.gov.uk/guidance/securing-loads-on-hgvs-and-goods-vehicles/4-ways-to-secure-a-load-in-an-hgv-or-goods-vehicle

このゲームは入門教材です。実車の積載・固縛では、車両、荷姿、固定器具、関係法令、事業者の作業手順に従ってください。
